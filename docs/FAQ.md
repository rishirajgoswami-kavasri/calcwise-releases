# CalcWise Frequently Asked Questions

## What is CalcWise?

CalcWise is a premium calculator application for Windows and Android.

## Which platforms does CalcWise support?

CalcWise supports Windows and Android.

## Does CalcWise work offline?

Yes. Core calculator functionality is designed to operate offline.

## Does CalcWise require an account?

No account is required to use its calculator functionality.

## Does CalcWise contain advertisements?

No.

## What calculator modes are available?

CalcWise provides:

- Standard
- Scientific
- Programmer

## Does CalcWise support calculation history?

Yes.

## Does CalcWise support memory operations?

Yes.

## Where can I download CalcWise?

Official production packages are distributed through approved application stores and official CalcWise release channels as applicable.

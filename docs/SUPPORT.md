## When Reporting a Problem

Please provide, where possible:

- CalcWise version
- Platform (Windows or Android)
- Operating system version
- Device model or computer configuration
- Description of the problem
- Steps required to reproduce it
- Screenshot of the issue, where appropriate

Please do not include passwords, authentication credentials, payment information, or other sensitive information in bug reports.

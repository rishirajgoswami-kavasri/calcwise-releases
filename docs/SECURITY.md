# CalcWise Security

Security and release integrity are important aspects of CalcWise development and distribution.

## Security Principles

CalcWise follows principles including:

- Offline-first calculator functionality
- Local calculation processing
- Minimal permissions
- Release signing
- Release integrity verification
- Controlled production builds
- Dependency review
- Defensive error handling

## Reporting a Security Issue

Security vulnerabilities should be reported privately.

**Security Contact:**

support@kavasritechnologies.online

Please include sufficient information for the issue to be investigated and reproduced.

Do not publicly disclose an unpatched security vulnerability before KAVASRI Technologies has had a reasonable opportunity to investigate and address it.

## Official Releases

Users are encouraged to install CalcWise only through official distribution channels.

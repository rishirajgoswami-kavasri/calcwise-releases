# CalcWise

Official Release Repository for CalcWise for Android and Windows.

CalcWise is a premium, privacy-focused calculator designed to deliver a fast, precise, and refined calculation experience across desktop and mobile devices.

## Latest Release

**Version:** 1.2.3  
**Release Type:** Production Release  
**Status:** Stable

## Supported Platforms

- Windows
- Android

## Features

- Standard Calculator
- Scientific Calculator
- Programmer Calculator
- Calculation History
- Memory Operations
- High-Precision Calculations
- Responsive and Adaptive Interface
- Keyboard Support
- Accessibility Support
- Offline-First Operation
- No Advertising

## Privacy

CalcWise is designed with privacy as a core principle.

Calculations are processed locally on the user's device.

See [Privacy Policy](docs/PRIVACY_POLICY.md).
